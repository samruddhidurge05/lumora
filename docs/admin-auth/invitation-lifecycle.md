# Lumora Admin Invitation Lifecycle

## Overview
This document specifies the end-to-end lifecycle states of an `AdminInvitation` record.

```
                  +-------------------+
                  |  POST /team/invite|
                  +-------------------+
                            |
                            v
                  +-------------------+
                  |      CREATED      |
                  +-------------------+
                            |
                            v
                  +-------------------+
                  |   EMAIL_QUEUED    |
                  +-------------------+
                     /             \
                    v               v
        +---------------+       +---------------+
        |  EMAIL_SENT   |       |  EMAIL_FAILED |
        +---------------+       +---------------+
                \                       /
                 v                     v
            +-------------------------------+
            |      POST /team/accept-invite |
            +-------------------------------+
                /            |            \
               v             v             v
       +----------+    +----------+   +----------+
       | ACCEPTED |    | REVOKED  |   | EXPIRED  |
       +----------+    +----------+   +----------+
```

---

## State Definitions

1. **CREATED / EMAIL_QUEUED**: Invitation generated by super admin. Security token (`invite_token`) issued with 48-hour expiration.
2. **EMAIL_SENT**: `EmailDispatcher` delivered the email via SMTP successfully.
3. **EMAIL_FAILED**: Delivery failed after 3 exponential backoff retries. The error log is recorded in `email_error_log`. Invitation token remains valid for manual sharing.
4. **ACCEPTED**: The matching user completed acceptance via `POST /api/admin/team/accept-invite`. Role elevated to `admin`.
5. **REVOKED**: Admin explicitly revoked the token via `POST /api/admin/team/invitations/{id}/revoke`. Blocked from future acceptance.
6. **EXPIRED**: Current time exceeds `expires_at`. Can be renewed using `POST /api/admin/team/invitations/{id}/resend`.
